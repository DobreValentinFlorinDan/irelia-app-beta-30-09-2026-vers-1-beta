Irelia Fieldbook

Evidence-based builds for Irelia one-tricks

Irelia Fieldbook is a local, single-user research tool for League of Legends players who main Irelia. It turns raw match data into actionable, statistically honest guidance: what high-Elite Irelia one-tricks actually build, and how those choices change per lane opponent and team composition. Everything runs on the player's own machine — no accounts, no servers, no third parties.

Verified one-trick analysis

Reads the KR/EUW/EUNE/NA ranked ladders and cross-references each account's top champion masteries to find players who genuinely main Irelia, then analyses their recent ranked games and timelines.

Evidence-based builds

Aggregates starting items, boots, core items, full purchase paths, runes, keystones, summoner spells and skill orders — including per-matchup breakdowns against each lane opponent.

Draft assistant

Optionally reads the player's own live champion select directly from the local League Client to surface the right matchup data during draft — a local read, no API call involved.

How the data is handled

  • Statistical honesty. Every percentage carries a sample size and a Wilson confidence interval, so small samples are never presented as reliable.
  • Patch-scoped. Build evidence is restricted to the newest patch with data, so stale-patch games never skew a recommendation.
  • Rate-limit discipline. A local token-bucket queue paces every request below the limits declared in the X-App-Rate-Limit response headers, and tolerates 429s by pausing rather than retrying aggressively.
  • Permanent caching. Every match and timeline is cached on disk and never re-fetched; timeline payloads are trimmed to the fields the analysis reads.
  • Local-only by design. The Riot API key is stored only in a local server process, never exposed to client code, and no data ever leaves the player's computer.
