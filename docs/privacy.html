Privacy Policy — Irelia Fieldbook

Last updated: October 2026

The short version: Irelia Fieldbook is a local-only application. It collects nothing. No account, no telemetry, no analytics, no tracking, no data leaves your machine.

1. What this application is

Irelia Fieldbook is a personal, non-commercial research tool for League of Legends players who main the champion Irelia. It runs entirely on your computer as a desktop application. There are no servers operated by the developer, and the developer never receives any data from the application.

2. Data the application processes

  • Riot Games match data. The application requests public match, ladder and mastery data from the official Riot Games API using your own API key. Responses are cached as local files on your disk (a cache folder inside the application directory) so repeat analyses don't re-request the same data.
  • Your League Client (optional). With your consent in the app, it can read your live champion select from the local League Client lockfile on your own machine. This is a local file read; no API request is made and nothing is transmitted.
  • Your Riot API key. Stored in a local .env.local file inside the application directory. It is read only by the local server process, is never bundled into client code, and is never sent anywhere other than the official Riot Games API.

3. Data we collect about you

None. The application has no login, no account system, no telemetry, no analytics, no crash reporting and no third-party SDKs. The developer has no way to see what the application does on your machine.

4. Third parties

  • Riot Games, Inc. — the official API (api.riotgames.com) and the public Data Dragon CDN (ddragon.leagueoflegends.com) are contacted directly by the application using your API key. See Riot Games' own Privacy Notice.
  • No other third party is contacted, and no advertising or analytics networks are used.

5. Data retention and deletion

All cached data lives in a cache folder inside the application directory. You can delete it at any time — either through the application's Data management screen ("Start fresh") or by deleting the folder. Deleting the folder removes every piece of data the application ever stored.

6. Children

The application does not collect personal information from anyone, including children under 13.

7. Changes to this policy

If this policy changes, the updated version will be published at this same URL with a new "last updated" date.
